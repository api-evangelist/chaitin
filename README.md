Chaitin Tech (长亭科技) is a Chinese cybersecurity company best known for SafeLine (雷池), a self-hosted, semantic-analysis Web Application Firewall and reverse proxy with 22k+ GitHub stars. Its broader security portfolio spans web application firewalling, vulnerability and risk assessment (X-Ray), automated penetration testing, asset exposure management (Cloud Atlas), container security (VeinMind), host workload protection (CloudWalker), API security (APISec), threat deception (D-Sensor), traffic threat detection (T-Answer), static application security testing (CodeInsight), and AI security tooling. Chaitin products expose machine APIs authenticated with a per-instance API token header (SafeLine uses X-SLCE-API-TOKEN on port 9443, /api/open/*) and are managed through a unified command-line tool, chaitin-cli, which also ships as an installable agent skill. Chaitin is backed by Qiming Venture Partners.

**Areas:** Security · Web Application Firewall · WAF · Cybersecurity · API Security · Container Security · Vulnerability Scanning · DevSecOps · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Chaitin Tech: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
